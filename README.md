# 💕 Happy Chinese Valentine's Day (七夕情人节) - Liquid Glass Card

A romantic, interactive Valentine's Day web app built with **Liquid Glassmorphism**, cute English & Chinese typography, particle animations, sound effects, and impossible-to-click "NO" button evasion physics.

## ✨ Features
- 🌸 **Liquid Glassmorphism**: Layered reflections, glowing mesh orbs, specular lighting.
- 🎨 **Cute Typography**: Google Fonts (`Fredoka`, `ZCOOL KuaiLe`, `Ma Shan Zheng`).
- 🤹 **Smart Evasion Physics**: "NO" button flees on hover/touch on desktop and mobile, while "YES" grows exponentially!
- 💖 **Canvas Ambient Engine**: Glowing floating hearts & twinkling stardust particles.
- 🔊 **Web Audio Synthesizer**: Built-in sound effects & romantic celebration arpeggio without external audio assets.
- 🎆 **Confetti Explosion**: Multi-stage celebration with classic Chinese romantic poetry quote.

## 🚀 Fast Push to Git & Deploy to Vercel

### 1. Initialize Git & Push to GitHub:
```bash
git init
git add .
git commit -m "feat: Liquid Glass Valentine Card"
# git remote add origin <YOUR_GITHUB_REPO_URL>

```

### 2. Deploy to Vercel in 10 seconds:
#### Option A: With Vercel CLI
```bash
npx vercel
```

#### Option B: Via Vercel Web Dashboard
1. Go to [vercel.com/new](https://vercel.com/new)
2. Import your GitHub repository
3. Click **Deploy** (Zero configuration required!)
